# Match 4

A small match-4 puzzle prototype for [PICO-8](https://www.lexaloffle.com/pico-8.php), written in Lua.

A 14 by 8 grid of five tile colors. Click a tile with the mouse to select it; the game finds and highlights runs of matching tiles horizontally and vertically.

## Play

1. Install PICO-8.
2. Download `match4.p8` and drop it into PICO-8's carts folder (type `folder` at the PICO-8 prompt to open it).
3. Type `load match4` and then `run`.

Controls: mouse to aim, left click to select a tile.

## Status

An early prototype: the grid, mouse input and match detection work; swapping, clearing and scoring aren't in yet.
